# VolMix 1.9 — Windows 11 音量混音器

一个**完全原创**的每应用音量混音器：不抄 EarTrumpet、不引入任何第三方开源代码，
界面观感与动画按 Windows 11 Fluent 规范手写实现。

## 直接运行

双击 **VolMix.exe**。程序常驻通知区域，**启动时完全静默**（不会自动弹出面板）。

| 操作 | 效果 |
| --- | --- |
| 左键单击托盘图标 | 打开 / 收起音量面板（面板出现在鼠标右侧） |
| 右键单击托盘图标 | 打开菜单：打开混音器 / 设置 / 退出 |
| 中键单击托盘图标 | 静音 / 取消静音当前默认播放设备 |

> Windows 11 会把新出现的托盘图标先放进「隐藏的图标」溢出区。
> 点击任务栏的 `∧`，把 VolMix 拖到任务栏上即可常驻显示。

## 功能

- **每应用音量与静音**：按进程合并同一应用的多个音频会话，拖动即时生效
- **输出设备主音量与静音**，以及**一键切换默认播放设备**
- **真·Windows 11 毛玻璃**：使用 DWM `DWMWA_SYSTEMBACKDROP_TYPE` 系统亚克力材质
  （Acrylic，与系统音量弹出面板同款），并启用系统的圆角与投影
- **与开始菜单一致的弹出 / 收回动画**：卡片从底边向上生长并淡入
  （Fluent 贝塞尔曲线 0.1/0.9/0.2/1.0），收回时向下收缩并淡出
- **面板出现在鼠标右侧**，垂直居中于鼠标；右侧空间不足时自动镜像到左侧
- **与 Win11 通知区域一致的单色托盘图标**：跟随任务栏深浅色，设备静音时自动变为静音图标
- 会话列表每 600 ms 自动刷新（仅面板显示时轮询）
- 应用图标由 exe 内嵌图标实时提取，取不到时用首字母圆角色块兜底

### 交互细节

| 操作 | 效果 |
| --- | --- |
| 拖动/点击滑块 | 实时改变音量；悬停时圆形滑块放大，按住时再大一点（没有多余外框） |
| 行上 `Ctrl` + 滚轮 | 微调该应用音量（±2%） |
| 行上点中键 | 该应用静音 / 取消静音 |
| 悬停某一行 | 行底色与右侧百分比淡入 |
| 设置页滚轮 | 上下滚动设置项（窗口高度超过屏幕时会自动限制高度并滚动） |
| `Esc` | 子页面返回混音器；在混音器页则关闭面板 |
| 点击面板外 | 面板收缩淡出 |

### 小彩蛋

设置页**右上角的小星星**与周围颜色不同（琥珀→粉色渐变）。连着点 **5 次**，
面板里会飘出黄棕色的「哼、哼、啊啊啊啊啊啊」，飘 5 秒后消失。

## 设置项

| 项目 | 说明 |
| --- | --- |
| 隐藏不活动的应用 | 只显示正在播放声音的应用 |
| 显示系统声音 | 是否显示 Windows 提示音的会话 |
| 显示输出设备音量 | 面板顶部是否显示主音量滑块 |
| 跟随系统主题 | 界面外观自动跟随 Windows 的浅色 / 深色 |
| 界面外观 | 固定为**浅色**或**深色**（关闭上面的开关后可选） |
| 开机时自动启动 | 写入 `HKCU\...\Run` 启动项（默认关闭，仅在你打开开关时写入） |
| 在开始菜单中显示 | 在开始菜单「所有应用」里保留 VolMix 快捷方式（默认关闭） |
| 语言 | 跟随系统 / 简体中文 / English，首次运行按 Windows 显示语言自动选择 |
| 退出 VolMix | 关闭程序并移除托盘图标 |

偏好保存在 `%APPDATA%\VolMix\settings.ini`，异常日志在同目录 `error.log`。

### 卸载

1. 托盘右键 → **退出 VolMix**
2. 删除本文件夹
3. 若开启过「在开始菜单中显示」，先在设置里关闭；同理关闭「开机时自动启动」
4. 删除 `%APPDATA%\VolMix`

## 原创性与实现说明

所有代码均为本项目手写，**未使用 EarTrumpet 或任何其他开源项目的源码与资源**：

- Core Audio（WASAPI）COM 互操作：`IMMDeviceEnumerator`、`IAudioSessionManager2`、
  `IAudioSessionControl2`、`ISimpleAudioVolume`、`IAudioEndpointVolume`、
  `IPropertyStore`、`IPolicyConfig` 等，按公开 API 文档手写
- 会话枚举、按进程分组、音量/静音读写、默认设备切换
- Win11 界面：DWM 亚克力背景、系统圆角与投影、Fluent 缓动曲线（手写三次贝塞尔
  缓动函数）、控件模板（滑块 / 开关 / 单选 / 图标按钮 / 菜单项 / 滚动条 / 提示）
- 运行时绘制：托盘单色图标（跟随任务栏主题与静音状态）、系统声音图标、
  首字母兜底图标、应用图标（手写 32bpp 多尺寸 .ico）

## 更新记录

### 1.9
- **修掉"开机后没点自己弹出来"**：1.0 时我加了"首次运行自动弹一次面板"的新手引导，
  判定条件是"设置文件不存在"。而打包验收会清理 `%APPDATA%\VolMix\settings.ini`，
  于是下一次启动又被当成首次运行自动弹面板；若系统禁止写该目录，则会**每次开机都弹**。
  现在 VolMix **完全静默启动**：不弹面板、不弹气泡提示，只保留托盘图标。
- **开机自启触发的重复启动也不会弹**：自启项改为写入 `"…\VolMix.exe" --startup`，
  带这个标记的第二实例直接静默退出；只有你**主动双击/启动** VolMix 时才会让已运行实例打开面板。
- 新增自检 `--checkquiet`，实测三种情况的可见性：
  - 正常启动 → `flyout visible=False`（不弹）
  - 开机自启触发的第二实例 → `flyout visible=False`（静默）
  - 用户主动再次启动 → `flyout visible=True`（打开面板，符合预期）
### 1.8
- **修掉"打开后第一次调节音量时圆形滑块不响应，第二次起才正常"**：圆点尺寸是代码驱动的，
  而它位于 Thumb 的嵌套模板里，首次应用模板时那个元素还没实例化，`_dot` 为 null 就直接返回了
  （要等第一次拖动结束的复位逻辑才把它找回来）。
  现在改为**懒解析**：`ApplyDotSize` / `UpdateFill` 取不到元素时会重新解析，并挂上 Thumb 的
  `Loaded` 事件补一次解析。实测：首次悬停即输出 `thumb size -> 24 (hover=True)`，
  像素测量显示悬停行圆点 30px、非悬停行 24px（24 DIP / 20 DIP 减去描边）
- **署名改为 Carlise**（GitHub 地址保持 https://github.com/CarIos233 不变）：
  设置页关于区域、LICENSE 版权行、程序集元数据同步更新
### 1.7
- **修掉"开机后第一次打开会在屏幕左上角闪一下"**：根因是先 `Show()` 再定位，窗口的第一帧还停在默认坐标 (0,0)。
  现在改为**先把窗口定位到鼠标右上再显示**，并且窗口构造时就先给一个合理位置，冷启动也不再闪。
- **修掉"改语言 / 改主题后设置页滚动条回到最上面"**：切换语言或主题会重建整个页面，
  新建的滚动视图偏移自然是 0。现在重建前记录设置页 / 设备页的滚动偏移，布局完成后再恢复。
  实测：切换前偏移 112 → 重建后从 112 继续滚动（最终 224），不再回顶。
### 1.6
- **修复开关圆点左右间距不对称**：打开状态时圆点距右边缘 8px，关闭状态距左边缘只有 4px。
  现在两种状态的近侧间距都是 4px（`TranslateTransform.X` 16 → 20）
- **点击"设置"后不再被屏幕底边挡住**：页面切换导致窗口变高时，会自动把窗口上移并夹紧在工作区内，
  进入设置页时额外**上移 1 厘米**（37.8px），保证最下面的"退出 / 关于"完整可见
- **托盘右键菜单新增一键切换语言**：菜单里直接显示"切换到英文 / 切换到简体中文"，不用进设置
- 语言仍可在设置 → 语言里选：跟随系统 / 简体中文 / English（首次运行按 Windows 显示语言自动选择）
### 1.5

### 1.4
- **滚轮彻底修复**：根因是面板经常抢不到前台焦点（托盘图标被 Explorer 转发点击时 `SetForegroundWindow` 会被系统拒绝），
  而滚轮消息默认只发给焦点窗口。现在三层保障：
  1) 显示面板时用 `AttachThreadInput + SetForegroundWindow` 强制获取前台；
  2) 在 `HwndSource` 消息层处理 `WM_MOUSEWHEEL`；
  3) 再加一个**低级鼠标钩子**（`WH_MOUSE_LL`）：只要指针在面板内，滚轮一律由面板消费并滚动，完全不受焦点影响。
  实测：真实注入滚轮（与真实鼠标同一条输入路径）时钩子捕获成功，偏移按 56px/格递增。
- **滑块圆点不再卡住变大**：原来用模板里的 `IsDragging` 触发器动画驱动尺寸，动画会粘在放大值上。
  改为代码驱动（静止 20 / 悬停 24 / 按下 26），松开后按当前是否悬停恢复，并把光标移开后必然回到 20。
  实测日志：`24 (hover=True)` → `20 (hover=False)`。
### 1.3
- **修复设置页滚轮不生效的根本原因**：WPF 的输入层会**直接丢弃非活动窗口的鼠标滚轮消息**
  （`HwndSource` 在窗口未激活时忽略 `WM_MOUSEWHEEL`），所以之前写在 WPF 事件层（`PreviewMouseWheel`）
  的处理根本收不到事件。现在改为在**窗口消息层**用 `HwndSource` Hook 捕获 `WM_MOUSEWHEEL`
  并直接驱动当前页面滚动，同时点击面板任意位置会重新把前台焦点抢回来。
  实测：每格滚动 56px，偏移 0 → 56 → 112 → 168 → 224 → 280（可滚动 292.7），
  截图画面同步位移（像素差异 12.7%）
### 1.2

- **修复音量滑块与左侧进度条不对齐**：填充条现在精确绘制到圆点圆心（自绘 `VolumeSlider`）
- **设置页支持鼠标滚轮滚动**，同时压缩了排版；窗口高度始终按屏幕工作区自适应

## 已知限制

- 商店（UWP）应用的行图标取自其宿主 exe。
- 托盘图标位置由 Windows 管理，可能需要在溢出区手动拖出一次。

- `IPolicyConfig` 为文档外接口，若未来 Windows 版本变更可能失效（已容错，不影响音量功能）。
