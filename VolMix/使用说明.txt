VolMix 1.9 —— Windows 11 音量混音器
作者：Carlise　GitHub：https://github.com/CarIos233
================================================

【怎么运行】
  双击 VolMix.exe。程序常驻系统托盘（通知区域），
  首次运行会自动弹出一次音量面板。

  Windows 11 通常会把新图标先放进托盘溢出区：
  点任务栏右下角的 ^ 箭头，把 VolMix 拖到任务栏上就能常驻。

【怎么用】
  左键点托盘图标         打开 / 收起音量面板（面板出现在鼠标右侧）
  右键点托盘图标         打开菜单（打开混音器 / 设置 / 切换语言 / 退出）
  中键点托盘图标         静音或取消静音当前默认播放设备

  面板里：
    - 顶部一行是“输出设备主音量”
    - 下面每一行是一个应用：图标、名称、音量滑块、静音按钮
    - 拖动滑块立刻改变该应用的音量；鼠标放上去圆点会放大
    - 悬停一行时右侧会显示百分比
    - 在行上按 Ctrl + 滚轮 可以微调该应用音量（每次 2%）
    - 中键点某一行 = 该应用静音 / 取消静音
    - 点标题栏的设备名可以切换默认播放设备
    - 右下角三个按钮：刷新 / 设置 / 关闭
    - 按 Esc 返回上一层，再按一次关闭面板
    - 点面板以外的任何地方，面板自动收缩淡出

【设置页可以改什么】（鼠标滚轮可以滚动设置页）
  隐藏不活动的应用      只显示正在播放声音的应用
  显示系统声音          是否显示 Windows 提示音的会话
  显示输出设备音量      面板顶部是否显示主音量滑块
  跟随系统主题          界面外观自动跟随 Windows 的浅色 / 深色
  界面外观              固定为“浅色”或“深色”
  语言                  跟随系统 / 简体中文 / English（首次运行自动按系统语言）
  开机时自动启动        在注册表 Run 项添加启动条目（默认关闭）
  在开始菜单中显示      在“所有应用”里保留 VolMix 快捷方式（默认关闭）
  退出 VolMix           关闭程序并移除托盘图标

【小彩蛋】
  设置页右上角有一个小星星（和周围颜色不一样）。
  连续点它 5 次，面板里会飘出黄棕色的“哼、哼、啊啊啊啊啊啊”，5 秒后消失。

【界面特性】
  - 真·Windows 11 毛玻璃（DWM 亚克力材质）+ 系统圆角与投影
  - 弹出 / 收回动画与 Windows 11 开始菜单一致（从底边生长 + 淡入淡出）
  - 托盘图标与 Win11 通知区域原生图标风格一致（单色，跟随任务栏深浅色，
    设备静音时自动变成静音图标）

【系统要求】
  Windows 11（推荐）/ Windows 10 1809 及以上，64 位
  .NET Framework 4.8（Windows 10 1903 之后与 Windows 11 系统自带，无需安装）
  不需要管理员权限，不需要联网。

【文件位置】
  程序本体           本文件夹里的 VolMix.exe
  偏好设置文件       %APPDATA%\VolMix\settings.ini
  界面截图           screenshots\
  自检日志           verification\
  完整源码           source\（双击 build.cmd 可重新编译）
  授权协议           LICENSE（MIT License）

【卸载】
  1. 托盘右键 → 退出 VolMix
  2. 删除本文件夹
  3. 如果开启过“在开始菜单中显示”或“开机时自动启动”，先在设置里关掉
  4. 删除 %APPDATA%\VolMix
